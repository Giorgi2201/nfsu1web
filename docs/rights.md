## Inputs and outputs

Supply your own legally obtained game installation. This repository provides
handwritten integration sources, tools, configuration and synthetic fixtures.
Do not publish game executables, assets, extracted sound-bank code, real
catalogs, translated game functions or compiled game modules. These belong in
ignored local directories, including when attaching files to issues or releases.
Do not contribute cracks, product keys or protection-bypass patches.

An executable fingerprint establishes compatibility with this tooling; it does
not establish the provenance, licensing or protection status of an input copy.
Ownership of a game copy alone does not settle every reverse-engineering or
distribution question. Applicable law and the terms for that particular copy
matter.

not legal immunity. Copyright, trademark, contract and anti-circumvention
questions may still arise. The project has not obtained EA's authorization or
a legal opinion establishing that every use is lawful. EA's
[current user agreement](https://www.ea.com/legal/user-agreement) restricts
reverse engineering except where authorized or permitted by law; that current
agreement does not establish which terms apply to a particular 2003 game copy.

GitHub can disable repositories under its
[DMCA takedown policy](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy),
including following qualifying circumvention claims. Its hosting safe harbor
is not a defense for repository authors. For a concrete complaint or an
assessment of the intended use in your jurisdiction, obtain legal advice.
Preserve any notice and permission records before deciding how to respond.
